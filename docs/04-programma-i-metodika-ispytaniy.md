# Программа и методика испытаний

Веб-платформа онлайн-обучения «Course Platform». По ГОСТ 19.301-79.

## 1. Объект испытаний

Веб-приложение «Course Platform» (Django), репозиторий https://github.com/ahmatovann/course-platform-kstu, ветка `main`.

## 2. Цель испытаний

Проверить, что все функциональные требования п. 4.1.1 (Ф-1 – Ф-14) и п. 4.1.2 (А-1 – А-6), разделение интерфейса по ролям (п. 4.1.4) и требования надёжности (п. 4.2) выполнены.

## 3. Требования к программе

Перечень требований — таблицы п. 4.1 и 7.2 технического задания. Каждому требованию ниже соответствуют ручные проверки и автотесты.

## 4. Средства и порядок испытаний

**Технические средства:** ПК с Windows 10/11, Python 3, браузер Chrome; для видео — файл .mp4.

**Подготовка:**

```powershell
git checkout main
git pull
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

**Автоматические испытания** — одна команда, Django создаёт отдельную пустую базу и удаляет её после:

```powershell
python manage.py test accounts quizzes progress courses adminpanel
```

Ожидаемый результат: `Ran 117 tests … OK`.
