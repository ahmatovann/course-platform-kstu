# Руководство администратора

Веб-платформа онлайн-обучения «Course Platform». По ГОСТ 19.505-79.

## 1. Назначение

Администратор наполняет платформу курсами, уроками и тестами, создаёт учётные записи и следит за прогрессом. Курсы сам не проходит (п. 4.1.4 ТЗ). Знание программирования не требуется: всё делается через **Панель администратора**.

## 2. Установка и запуск (для разработчика)

```powershell
git clone https://github.com/ahmatovann/course-platform-kstu.git
cd course-platform-kstu
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Сайт откроется по адресу http://127.0.0.1:8000. Первый администратор создаётся командой `createsuperuser`.

**Почта.** Чтобы письма уходили на настоящую почту, создайте рядом с `manage.py` файл `.env` по образцу `.env.example`: `GMAIL_ADDRESS` и `GMAIL_APP_PASSWORD` (пароль приложения Google, 16 букв). Файл `.env` в Git не попадает. Без него письма печатаются в терминал.

**База данных** — файл `db.sqlite3` в корне проекта; показать её устройство: `python manage.py dbinfo`. Резервная копия — копия этого файла и папки `media/` (видео, материалы, аватары).

## 3. Вход в панель

Войдите своей почтой и паролем — сразу откроется **Панель администратора** (`/panel/`). У администратора нет каталога, «Моих курсов» и «Моего прогресса». Слева меню: **Обзор, Курсы, Пользователи, Прогресс**. Стандартная админка Django остаётся доступна по ссылке **Django admin**.

**Обзор** показывает число курсов (и сколько опубликовано), уроков, учеников (и сколько заблокировано), записей на курсы, попыток тестов, выданных сертификатов и последние попытки тестов.

## 4. Курсы (А-1)

1. **Курсы → + Новый курс**: название, описание, галочка «Опубликован». Без галочки курс скрыт и в каталоге не виден.
2. В списке курсов кнопка **Опубликовать / Скрыть** меняет видимость одним нажатием.
3. **Изменить** — правка названия и описания.
4. **Как видит ученик** — открыть карточку курса глазами обучающегося.
5. **Удалить курс** (на странице курса) удаляет его вместе с уровнями, уроками, тестами и записями учеников — сайт переспросит.

## 5. Уровни (А-2)

На странице курса: **+ Уровень** — название и номер. Номер ставится следующим автоматически. Уровни открываются ученику по порядку номеров; два уровня с одним номером в курсе сохранить нельзя.

Порог прохождения теста задаётся в тесте уровня (раздел 7).

## 6. Уроки и материалы (А-3)

1. В уровне нажмите **+ Урок**: название, номер, описание.
2. Видео — **файлом** (.mp4, .webm, .ogg, .mov) или **ссылкой** (YouTube или прямая ссылка на .mp4).
   - Для файла и прямой ссылки урок отметится просмотренным после 90 % видео.
   - Для YouTube ученик отмечает урок кнопкой «Отметить урок как изученный».
3. После сохранения урока справа появится блок **Материалы урока**: название и файл (PDF, презентация, документ, аудио, архив). Другие типы файлов (например, .exe) не принимаются.
4. **Посмотреть, как видит ученик** — открыть урок в режиме просмотра (отметки не сохраняются).

## 7. Конструктор тестов (А-4)

1. В уровне нажмите **+ Создать тест**: название и **порог сдачи** в процентах (1–100, по умолчанию 80).
2. **+ Вопрос**: текст вопроса, от 2 до 4 вариантов, отметка **правильного варианта**. Пустой вариант нельзя отметить правильным.
3. У вопроса видно, какой вариант верный (ученик этого не видит).
4. **Изменить / Удалить** — у каждого вопроса.

## 8. Пользователи (А-5)

1. **Пользователи → + Новый пользователь**: почта и имя. Пароль придумывает сайт и отправляет на почту вместе с логином. Если письмо не ушло, пароль покажется на экране — передайте его человеку.
2. Поиск по почте или имени, фильтр «Активные / Заблокированные».
3. **Заблокировать** — человек больше не сможет войти. **Разблокировать** — вернуть доступ.
4. **Новый пароль** — сайт выдаёт новый случайный пароль и отправляет на почту; старый перестаёт действовать.
5. Администраторов в этом списке нет — их нельзя заблокировать из панели.

## 9. Прогресс пользователей (А-6)

- **Прогресс** — все записи на курсы: ученик, курс, дата записи, процент, отметка «курс пройден». Фильтр по курсу.
- **Подробнее** (или **Прогресс** в списке пользователей) — прогресс одного человека по каждому курсу и уровню: статус уровня, просмотренные уроки, лучший результат теста, число попыток, сертификаты.

## 10. Запись ученика на курс (сверх ТЗ)

По ТЗ ученик записывается на курс сам (Ф-6). Администратор тоже может открыть ученику курс:

1. **Прогресс → Записать ученика на курс**: выберите ученика и курс, нажмите **+ Записать**. Курс сразу появится у ученика в «Моих курсах». То же — на странице **Подробнее** конкретного ученика.
2. Записать можно только на **опубликованный** курс: скрытый курс ученик не увидит.
3. **Отчислить** — в строке таблицы прогресса или в карточке курса ученика. Курс пропадёт из «Моих курсов»; просмотренные уроки и попытки тестов сохраняются и вернутся, если записать снова.

На странице курса подсказка **«Как наполнить курс»** показывает 4 шага (уровень → уроки → тест → публикация); сделанные шаги отмечены зелёным с галочкой. На **Обзоре** — **Быстрые действия**: новый курс, тест к уровню, новый пользователь, запись на курс.

## 11. Возможные ошибки

| Сообщение | Причина и что делать |
| --- | --- |
| «Уровень с таким номером в курсе уже есть» | выберите другой номер |
| «Загрузите видео в формате .mp4…» | загружен не видеофайл |
| «Можно загрузить PDF, презентацию…» | неподдерживаемый тип материала |
| «Правильный вариант не может быть пустым» | заполните отмеченный вариант или отметьте другой |
| «Сначала сохраните тест уровня» | создайте тест, потом добавляйте вопросы |
| «Аккаунт создан, но письмо не отправилось» | проверьте `.env` и интернет; передайте пароль с экрана |
| «Почта не настроена — письма не уходят» (на Обзоре) | на этом компьютере нет файла `.env`: создайте его по образцу `.env.example` и перезапустите `runserver`; до этого пароли и ссылки «Забыли пароль?» печатаются в терминале |
| «Этот раздел доступен только администратору» | вошли учётной записью ученика |
